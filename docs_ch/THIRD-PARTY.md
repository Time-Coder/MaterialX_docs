# 第三方软件和服务

MaterialX 项目还使用以下免费提供给开源项目的软件和服务：

- [CMake](https://cmake.org/) 用于跨平台构建
- [GitHub Actions](https://github.com/features/actions) 用于持续集成
- [PVS-Studio](https://pvs-studio.com) 和 [Cppcheck](https://cppcheck.sourceforge.io/) 用于静态分析
