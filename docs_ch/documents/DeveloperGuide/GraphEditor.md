# MaterialX 图形编辑器

- [English](../../../docs_en/documents/DeveloperGuide/GraphEditor.md)
- [简体中文](GraphEditor.md)

MaterialX 图形编辑器是一个用于可视化、创建和编辑 MaterialX 图形的示例应用程序。它使用 ImGui 框架以及额外的 ImGui 扩展（如节点编辑器）。

## 构建 MaterialX 图形编辑器
在 CMake 中选择 `MATERIALX_BUILD_GRAPH_EDITOR` 选项来构建 MaterialX 图形编辑器。安装会将 **MaterialXGraphEditor** 可执行文件复制到所选安装文件夹内的 `/bin` 目录中。

## 图形编辑器功能摘要

1. **`加载材质`**：加载 MTLX 格式的材质文档。
2. **`保存材质`**：将图形保存为 MTLX 格式的材质文档。
3. **`新建材质`**：清除所有信息以准备创建新材质
4. **`节点属性编辑器`**：查看或编辑所选节点的属性。
5. **`渲染视图`**：查看渲染的材质。

## 按钮

要显示新的材质和图形，请点击 `加载材质` 按钮并导航到 [Materials/Examples](https://github.com/AcademySoftwareFoundation/MaterialX/tree/main/resources/Materials/Examples) 文件夹，该文件夹包含一组 MTLX 格式的材质，然后选择要加载的文档。图形编辑器将显示所选文档的图形层次结构以供可视化和编辑。

要将图形的更改保存为 MTLX 文件，请点击 `保存材质` 按钮。这还将保存图形中节点的位置以供将来使用。

## 编辑器窗口

MaterialX 文档在编辑器窗口中显示为节点。首次加载文件时，将显示材质节点、表面着色器节点以及任何封闭的节点图。双击节点图或任何定义为子图的节点将显示该图的内容。

当前图形层次结构显示在编辑器上方。要返回并退出子图，请点击图形名称左侧的 `<` 按钮。

每个节点和节点图都显示其名称以及所有输入和输出的引脚。通过点击一个节点的输出引脚并将其连接到另一个节点的输入引脚来连接节点，从而创建链接。只有当输入和输出引脚具有相同的类型（由引脚的颜色指定）时，才能创建链接。创建新链接时，渲染视图中的材质将自动更新。

在编辑器中使用 Tab 键允许用户通过弹出 `添加节点` 窗口来添加特定节点。节点在弹出窗口中根据其节点组进行组织，但也可以通过名称搜索特定节点。要创建节点图，请在 `添加节点` 弹出窗口中选择 `节点图`，然后深入该节点以在其中添加节点并填充它。

为了将节点图连接到着色器，请在节点图内添加输出节点，然后返回到节点图外部，并将相应的输出引脚连接到表面着色器。默认情况下，节点图不包含任何输出节点或引脚。

`添加节点` 弹出窗口中存在的另一种节点类型是组或背景节点。此背景节点可用于通过将特定节点拖放到背景节点上来对它们进行分组和标记。

要在编辑器窗口中搜索特定节点，请使用 `CTRL` + `F` 来调出搜索栏。

## 节点属性编辑器
当在图形中选择节点时，其信息显示在左侧列的 `节点属性编辑器` 中。此编辑器显示节点的名称、类别、输入、输入名称、类型和值。连接到其他节点的输入不会显示值。

这是可以调整节点属性（如其名称和输入值）的地方。当输入值更改时，材质会自动更新以反映该更改。节点信息按钮显示所选节点及其输入的 `doc` 字符串（如果存在）。此 `doc` 字符串目前是只读的。

"显示所有输入"复选框显示节点的所有可能输入。取消选中该框时，仅显示具有连接或已设置值的输入。保存图形时，仅会保存这些输入。

## 渲染视图
在 `节点属性编辑器` 上方，`渲染视图` 在 Arnold Shader Ball 上显示当前材质。如果在子图内，它将显示与该子图关联的材质；否则，它将显示所选节点的输出。当对图形进行任何更改时，它会自动更新。

要调整节点属性编辑器和渲染视图窗口的相对大小，请在应用程序中拖动这些窗口之间的分隔符。可以使用鼠标左键或右键操作着色器球来更改渲染视图窗口的相机。

## 键盘快捷键

- `TAB`：添加节点弹出窗口
- `右键单击`：沿编辑器平移
- `双击节点`：如果节点有子图，则深入该子图
- `U`：向上并退出子图
- `F`：框选所选节点
- `Ctrl + F` 按名称在编辑器中搜索节点
- `Ctrl/Cmd + C` 复制节点
- `Ctrl/Cmd+X` 剪切节点
- `Ctrl/Cmd+V` 粘贴节点
- `+` ：当鼠标位于渲染视图窗口上时，用相机放大。
- `-` ：当鼠标位于渲染视图窗口上时，用相机缩小。

## 命令行选项

以下是 MaterialXGraphEditor 的常见命令行选项，完整列表可以通过 `--help` 选项显示。
- `--material [FILENAME]` ：指定要在图形编辑器中显示的 MTLX 文档的文件名
- `--mesh [FILENAME]` ：指定要在图形编辑器中显示的 OBJ 或 glTF 网格的文件名
- `--path [FILEPATH]` ：指定额外的数据搜索路径位置（例如 '/projects/MaterialX'）。在定位数据库、XInclude 引用和引用图像时将查询此绝对路径。
- `--library [FILEPATH]` ：指定额外的数据库文件夹（例如 'vendorlib', 'studiolib'）。在加载数据库时，此相对路径将附加到数据搜索路径中的每个位置。
- `--captureFilename [FILENAME]` ：指定第一个渲染帧应写入的文件名

## 已知限制

- 尚不支持使用输入的 `channels` 属性创建新连接，尽管现有的 `channels` 连接将在图形中显示。
- 尚不支持为输入分配新的 `colorspace` 属性，尽管渲染视图将尊重输入上现有的 `colorspace` 属性。
